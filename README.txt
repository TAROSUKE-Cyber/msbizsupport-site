# MSビジネスサポート Webサイト一式

## 使い方
1. このフォルダの `index.html` と `assets` フォルダを GitHub Pages のリポジトリにアップロードしてください。
2. `index.html` 内の動画リンク `href="#"` を、YouTube等で公開した実際の動画URLに差し替えてください。
3. 画像を差し替える場合は、`assets/hero.png` または `assets/logo.png` を同じファイル名で置き換えると、HTMLを変更せずに反映できます。

## Jekyllテーマについて
この `index.html` はテーマに依存しない1ページ型の静的HTMLです。
GitHub Pagesのテーマを選ばなくても、そのまま公開できます。
